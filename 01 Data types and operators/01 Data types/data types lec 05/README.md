# Data Types and Operators - Lecture 05

A comprehensive collection of C programming examples and practice problems focusing on data types, operators, and variable manipulation techniques.

## Objectives

- Master ternary (conditional) operators and nested expressions
- Understand logical and bitwise operators in C
- Learn various number swapping techniques
- Practice printf() function with complex expressions
- Develop proficiency in arithmetic and bitwise operations

## Topics Covered

- **Ternary Operators**: Conditional expressions and nested ternary operations
- **Logical Operators**: AND, OR, NOT operations in C
- **Bitwise Operators**: AND, OR, XOR, shift operations
- **Variable Swapping**: Multiple techniques (temp variable, arithmetic, XOR)
- **Arithmetic Operations**: Addition, subtraction for variable manipulation
- **printf() Behavior**: Format specifiers with complex expressions
