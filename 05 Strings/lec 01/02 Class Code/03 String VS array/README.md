# String vs Array - Class Code

This folder contains C code examples demonstrating the differences and relationships between strings and arrays in C programming.

## Topics Covered

- Array name as pointer
- String name as pointer
- Operations on arrays
- Operations on strings
- Using pointers in arrays
- Smart use of pointers with arrays
- New strings in arrays
- Pointer operations in strings
- Increment operations
